# Project Context

## Purpose
This is an existing Jhipster project where I have added some new entities so that it can work as a multitenant app - see jhipster-model.jdl. The UI is basic crud style and although it enforeces authentication on certain apis, many of them do not enforce authorization e.g. certain users should not be able to see certain rows of certain tables
